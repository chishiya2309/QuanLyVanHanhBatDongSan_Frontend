# UC18 — Bố trí và theo dõi tài sản

Frontend mở rộng module UC17 của RentOps cho Host, truy vết FC-03-16–FC-03-17 và US-02. Không thay đổi backend. Backend controller/DTO và `docs/UC18.md` của repository backend là hợp đồng API.

## Giao diện và điều hướng

| URL (giữ thêm q/page/size) | Nội dung |
| --- | --- |
| `/assets` | Danh sách, cột phòng hiện tại, thao tác theo currentPlacement |
| `/assets/:assetId` | Chi tiết và snapshot lúc bắt đầu bố trí |
| `/assets/:assetId/history` | Hai phần lịch sử độc lập, đầy đủ, theo thứ tự backend |
| `/assets?placement=assign&targetAssetId=:assetId` | Modal gán trên danh sách |
| `/assets?placement=transfer&targetAssetId=:assetId` | Modal chuyển trên danh sách |
| `/assets/:assetId?placement=assign` | Modal gán trên chi tiết |
| `/assets/:assetId?placement=transfer` | Modal chuyển trên chi tiết |

Modal dùng native dialog, có focus trap/Escape/backdrop/phục hồi focus. Mở dùng pushState; Hủy loại tham số modal bằng replaceState, kể cả truy cập trực tiếp. Back/Forward được hỗ trợ; mỗi lần modal mount lấy lại chi tiết và danh sách phòng. URL modal sai/thiếu UUID, action lạ, tham số lặp hoặc xung đột create được chuẩn hóa về màn nền cùng thông báo chọn lại; không gửi POST.

Chờ bootstrap phiên và quyền HOST trước mọi API UC18/phòng. Giữ menu Tài sản trên desktop/mobile, shell, hồ sơ và đăng xuất; bộ chọn cơ sở và dashboard mẫu tiếp tục được ẩn. Không xóa phiên khi điều hướng riêng tư.

Phòng đích lấy toàn phạm vi Host, nhãn gồm khu vực/tòa nhà/tầng/mã/tên. Chỉ loại phòng nguồn khi chuyển; không loại phòng đang thuê/bảo trì hoặc cấm tài sản RETIRED. Không có thao tác thu hồi, đặt lịch, sửa/xóa lịch sử, xóa tài sản hay batch.

## API và đồng bộ

| Method | Endpoint dưới /api/v1 | Body | Thành công |
| --- | --- | --- | --- |
| POST | `/assets/:assetId/placements` | `{roomId}` | 201, Gán tài sản vào phòng thành công |
| POST | `/assets/:assetId/transfers` | `{roomId,sourcePlacementId}` | 200, Chuyển tài sản thành công |
| GET | `/assets/:assetId/history` | — | 200, AssetHistory |
| GET | `/rooms/search` | — | 200, mảng phòng |

Giữ GET danh sách/chi tiết UC17; Asset yêu cầu `currentPlacement` có mặt, giá trị null hoặc DTO placement hợp lệ. Dữ liệu thiếu/sai không được biến thành chưa bố trí hoặc lịch sử trống. Codec tiền lossless không đổi. DTO lịch sử tình trạng có thêm liên kết phòng; DTO POST condition-records UC17 giữ nguyên.

Mọi request dùng credentials/include, Accept JSON và no-store. POST lấy CSRF qua helper, gửi header động; GET nhận AbortSignal. GET được bảo vệ bằng khóa resource, AbortController và generation của hook, kết hợp epoch tài khoản tại sessionClient, nên đổi query modal không làm hủy nhầm request màn nền còn cùng identity. Mutation vẫn kiểm tra cả route và phiên. Không thêm retry; giữ một authenticated replay sau 401 của hạ tầng phiên hiện có.

Modal giữ snapshot nguồn của GET khởi tạo; `sourcePlacementId` chính là nguồn Host nhìn thấy. Không dùng updatedAt hoặc nguồn mới để âm thầm gửi lại. Lock đồng bộ trước CSRF ngăn double submit. Sau success/conflict kết thúc modal, refresh resource liên quan; không có cache lịch sử dùng chung qua route. GET cũ và callback modal đã unmount không cập nhật màn mới.

Gán/chuyển không gửi thời điểm, Host, Account hoặc tình trạng; không gọi condition-records. Chuyển chỉ một POST nguyên tử. Frontend không mô phỏng rollback hay transaction. Lỗi GET sau thành công giữ banner thành công và khóa dữ liệu stale. Mất response/response ghi sai cấu trúc báo kết quả chưa xác định, đóng ý định cũ, tải lại và yêu cầu người dùng chủ động bắt đầu mới.

Lịch sử vị trí hiển thị khoảng `[fromAt,toAt)` và snapshot conditionAtStart; null kết thúc ghi “Chưa kết thúc”. Lịch sử tình trạng giữ đủ từng lần ghi nhận, tài khoản dạng UUID và phòng của chính liên kết placement. Null placement luôn hiển thị không có phòng tại thời điểm ghi nhận. Không suy từ phòng hiện tại hoặc thời điểm ở client; không giả tên người ghi nhận. Tên/mã phòng là nhãn backend trả về, không phải snapshot tên trước khi đổi tên. So sánh khoảng tại codec giữ đến nanosecond; hiển thị ngày giờ vi-VN/Asia/Ho_Chi_Minh qua time/dateTime gốc.

## Đối chiếu đặc tả và kiểm thử

| Luồng | UI/hành vi | Kiểm thử |
| --- | --- | --- |
| Chính: gán | Fresh GET, chọn phòng, xác nhận, 201, refresh | API contract, form, browser lifecycle |
| A: chuyển | Fresh source, loại phòng nguồn, sourcePlacementId, 200 | API body, source validation, browser lifecycle |
| B: lịch sử | Hai phần độc lập, read-only, không giả bối cảnh | Codec, history integration, browser history |
| C: chưa có tài sản | Giữ empty state UC17, không tự tạo dữ liệu | UC17 loading/search/browser |
| D: không có phòng | Thông báo riêng, disable xác nhận, vẫn xem lịch sử | Room empty/error integration/browser |
| E: hết phiên | Kết thúc auth theo cơ chế hiện có, gỡ dialog/dữ liệu | Authorization integration/browser |
| F: không có quyền | Gỡ module dữ liệu; không gọi API với role khác | Role/fatal integration/browser |
| G: thiếu lựa chọn | Client không POST; backend 400 kết thúc về danh sách | Form/API/400 integration |
| H: tài sản không khả dụng | Về danh sách, notice, refresh | 404 asset integration, UC17 regression |
| I: phòng không khả dụng | Giữ modal, clear selection, refresh rooms | 404 room integration/browser |
| J: trùng phòng | Giữ modal, yêu cầu chọn lại, focus select | 409 same-room integration/browser |
| K: thời điểm/chồng lấn | Đóng ý định, notice, refresh, không retry | 409 codec/API/integration |
| L: gán bị thay đổi | Dừng gán, không tự đổi thành chuyển | Fresh-mode/conflict integration |
| M: nguồn thay đổi | Dừng chuyển, không tự thay sourcePlacementId | Source/conflict integration/browser |
| N/O: lỗi ghi | Message theo endpoint, kết thúc ý định, không retry | API fallback/integration/browser |
| P: lỗi lịch sử | Error/retry, không thành empty | History integration/browser |

Các file test chính: `assetPlacementsApi.test.ts`, `assetPlacements.test.tsx`, `tests/browser/asset-placements-browser.mjs`; giữ hồi quy assetsApi/assets và bộ browser UC17. Fixture nằm riêng trong tests, cập nhật currentPlacement=null trong fixture UC17. Script mới: `npm run test:browser:asset-placements`.

Chạy build, lint, npm test, browser UC17 và browser UC18 với Vite tại 127.0.0.1:5173. Vitest giới hạn hai jsdom worker để bộ test đầy đủ không làm cạn bộ nhớ máy Windows. Browser chạy Chrome/Edge headless, API intercept chỉ trong test; ảnh và report lưu tại `.hallmark/shots/asset-placements`, không phải chứng nhận Hallmark.
